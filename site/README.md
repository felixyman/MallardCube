# MallardCube docs

Documentation site built with [Starlight](https://starlight.astro.build).

## Run locally

```bash
bun install
bun run dev
```

The dev server starts at `http://localhost:4321`.

## Build

```bash
bun run build
```

Static output is written to `dist/`.

## Layout

Content lives in `src/content/docs/`. The sidebar is configured in
`astro.config.mjs`.
